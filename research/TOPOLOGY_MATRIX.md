# 数据中心接网与拓扑分类矩阵（组会草稿）

| 维度 | 建议分类 | 对预测边界/输入的影响 | 本周要确认的问题 |
|---|---|---|---|
| 功率等级 | 小型 / 中型 / 大型 / hyperscale | 规模影响波动、爬坡率、冗余和接网电压等级 | 采用什么阈值与权威来源？ |
| 接网结构 | 单路 / 双路 / 多路冗余供电 | 多个进线点是否都可测；预测对象是单点还是聚合值 | PCC 的定义是否一致？ |
| 现场新能源 | 无 / 光伏 / 风电 / 混合 | PCC 净负荷不再等于数据中心总用电 | 是否能获得发电侧计量？ |
| 储能与 UPS | 仅 UPS / BESS / 混合 | 充放电改变 PCC 功率和短时波动 | 充放电状态是否可观测？ |
| 微网/孤岛能力 | 无 / 可孤岛 / 多能源协同 | 运行模式切换可能造成结构突变 | 是否需要模式分类变量？ |
| 工作负载调节 | 不可延迟 / 可延迟 / 混合 | IT 调度影响负荷的时间分布 | 是否能拿到 workload proxy？ |
| 冷却 | 风冷 / 液冷 / 混合 | 温度与湿度的敏感度不同 | 天气变量应来自哪里？ |

建议在汇报中把“拓扑改变测量边界和可观测变量”与“预测算法本身”分开讲，避免直接断言每种拓扑一定需要完全不同的算法。
